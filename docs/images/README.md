# Capturas de demonstração

`letters.png` e `qwerty.png` foram capturadas do teste SDL nativo da versão 1.0.0,
com remote e nomes de arquivos fictícios, e convertidas de BMP para PNG sem
alterar o conteúdo. Não são fotografias do console nem contêm arquivos de uma
conta real do Google Drive. O ícone é a arte aprovada em `app/icon.png`.
